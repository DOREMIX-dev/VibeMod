# Журнал версий

Версия повышается после каждых пяти завершённых изменений.

## 0.81
База счётчика после переноса прежнего проекта на MDK и реализации основных механик.

## 0.82
1. Java toolchain и закреплённый ForgeGradle.
2. Единый VERSION, Gradle и Manifest.
3. Predicate API отмены событий Forge.
4. Клиентский Gui API и клавиши R/Z/X.
5. pack.mcmeta и явная регистрация GameTest.

Следующая группа, зафиксированная до утраты окружения:
1. Эффекты лавы, полоса стены пламени, замедление бури.
2. Отдельные каталоги запусков.
3. Проверка ресурса арены с учётом preset GameTest.
4. Русские инструкции и отчёт об ограничениях.

## 0.83
5. Восстановление проекта из истории в GitHub и подготовка автоматической сборки.

Это реконструкция, не идентичный бинарный релиз 0.82. Текущие проверки фиксируются Actions.

## 0.84
1. Восстановлены Gradle Wrapper и скрипты запуска.
2. Добавлены игровые тесты изоляции дуэли, отсчёта и получения уровня.
3. Книга показывает опыт стихии и блокирует повторное изучение на клиенте.
4. Синхронизация отправляет только разрешённые поля интерфейса.
5. Сервер повторно проверяет уровень и родителей при применении заклинания.
