# Статус проверки восстановленной ревизии

Локальная компиляция недоступна: рабочее окружение offline. Прежние журналы 0.82 не восстановлены и не доказывают работоспособность этой ревизии.

Подготовлены 4 JUnit-теста и 4 GameTest-теста. Их текущий результат необходимо смотреть в GitHub Actions и артефакте test-reports. Наличие workflow не означает успешный запуск.

Проверяются каталог и доступность заклинаний, шесть комбинаций, рейтинг, пределы стоимости, серверный расход маны, перезарядки, требования изучения, NBT Clone и наличие ресурса измерения. GameTest создаёт собственный preset без пользовательского измерения: наличие ресурса не подтверждает загрузку арены обычным сервером.

Пока не подтверждены: компиляция реконструкции, визуальная работа клиента, подключение двух игроков, полный цикл дуэли, возврат между измерениями, восстановление после аварии, одновременные арены и совместимость со сторонними модами. Интерфейс представлен вкладками и зависимыми способностями, без графа соединительных линий.

В реконструкции дополнительно проверяется результат teleportTo перед удалением точки возврата и привязка разрешённого урона к конкретной паре атакующий/цель. Эти изменения требуют повторных игровых проверок.
