# Arcane Realms 0.83 — восстановленная тестовая версия

Minecraft Java 26.3 · Forge 66.1.2 · Java 25. Mod ID: `arcanerealms`, сохранён для совместимости.

Проект восстановлен по истории разработки. Готовность этой ревизии определяется результатом Actions, а не прежней сборкой 0.82.

## Получение мода

Откройте вкладку **Actions**, последний успешный запуск **Build Arcane Realms**, затем скачайте артефакт **Arcane-Realms**. В ZIP находится **Arcane-Realms.jar**. Если запуск красный, сборка не подтверждена; отчёты доступны в **test-reports**. Исходники скачиваются через **Code → Download ZIP**.

Установите Forge 66.1.2 для Minecraft Java 26.3 и поместите JAR в папку `mods` клиента и сервера. Для первого запуска используйте отдельный мир. JAR должен быть одной версии у сервера и игроков.

## Управление

K — книга. Нажмите название заклинания для изучения, затем «В слот». R/Z/X — три выбранных заклинания; клавиши настраиваются. Мана восстанавливается на 2 в секунду. Стартовые 5 очков позволяют изучить пять базовых стихий; применение магии даёт опыт и новые очки при повышении уровня.

В книге введите имя игрока рядом и выберите Мир / Арена / Рейтинг. Соперник принимает вызов в своей книге. Отсчёт — 5 секунд; радиус — 24 блока; лимит — 5 минут. Есть сдача, ничья по соглашению и поражение при отключении. Рейтинг меняется только в режиме «Рейтинг».

Команды: `/arcane status`, `/arcane skills`, `/arcane unlock <spell>`, `/arcane cast <spell>`.
Дуэли: `/arcane duel challenge <player> <world|arena|ranked>`, `/arcane duel accept`, `decline`, `surrender`, `draw`.

## Реализованные механики

23 заклинания, пять стихий, шесть обязательных комбинаций, серверные снаряды и поля, столкновение огня со льдом с частицами пара; мана, опыт, уровни, очки и перезарядки. Прогресс переносится после смерти. Отдельное измерение арены содержит до 32 разнесённых площадок. Точка возврата сохраняется до перемещения. Магия не меняет блоки; инвентарь не копируется. Страж — временный стационарный голем с магической атакой.

## Разработка

Установите Java 25 и Gradle 9.7.1. Выполните `gradle build runGameTestServer`. Результат — `build/libs/Arcane-Realms.jar`.
Служебный JDK для launcher загружается через resolver. Интернет необходим.
Клиент: `gradle runClient`; сервер: `gradle runServer`. Gradle Wrapper не восстановлен: бинарный файл прежнего архива недоступен.

Официальный MDK: https://maven.minecraftforge.net/net/minecraftforge/forge/26.3-66.1.2/forge-26.3-66.1.2-mdk.zip

Ограничения и статус тестов — VALIDATION.md. Версия повышается раз в пять изменений, журнал — CHANGELOG.md.
